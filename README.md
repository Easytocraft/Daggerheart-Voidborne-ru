# Daggerheart: Voidborne — русский перевод

Неофициальный русский перевод модуля [Daggerheart: Voidborne](https://git.geeks.gay/cosmo/daggerheart-voidborne) (автор — Cosmo) для Foundry VTT v13–v14.

Перевод работает **поверх** оригинального модуля через [Babele](https://foundryvtt.com/packages/babele): исходные компендиумы не меняются, поэтому перевод не конфликтует с обновлениями оригинала.

## Что переведено

| Компендиум | Содержимое |
|---|---|
| Классы и варианты классов | классы, подклассы, способности, карты домена Крови, предметы класса, папки |
| Противники и окружения | карточки, описания, мотивы и тактики, способности, действия, эффекты, отсчёты |
| Макросы | названия и все сообщения в чате и уведомления |

Также переводится подпись домена «Blood» → «Кровь» (в настройках homebrew системы Daggerheart; делает ведущий, только если подпись ещё не менялась).

## Установка

1. Установите модуль **Babele** и сам **Daggerheart: Voidborne**.
2. В Foundry: *Настройки → Модули → Установить модуль*, вставьте ссылку на манифест:
   `https://github.com/Easytocraft/Daggerheart-Voidborne-ru/releases/latest/download/module.json`
3. Включите в мире Babele, Voidborne и этот перевод.
4. В настройках Foundry выберите язык **Русский**.

## Терминология

Согласована с русскими терминами Daggerheart: Hope — Надежда, Fear — Страх, Stress — Стресс, HP — хиты, Evasion — Уклонение, Proficiency — Мастерство, Spotlight — фокус, Minion — Приспешник, Horde — Орда, Countdown — Отсчёт, Hex — Порча, Favor — Благосклонность, Focus — Концентрация. Правки терминов — через Issues или Pull Request.

## Структура

```
module.json                      манифест
scripts/ru.js                    регистрация в Babele и конвертеры
lang/ru.json                     заглушка языка
translations/ru/*.json           файлы перевода (по одному на компендиум)
```

Записи в файлах переводов ключуются по `_id` и дополнительно по английскому названию. Если оригинал добавит новые записи, они просто останутся на английском до обновления перевода.

## Как внести правку

Откройте нужный файл в `translations/ru/`, найдите запись по английскому названию или `_id` и поправьте поля `name`, `description`, `actions` и т. д. HTML-теги, `@Lookup[@name]`, `[[/r ...]]` и `@UUID[...]` менять не нужно.
